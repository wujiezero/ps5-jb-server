# PS5 设备控制台设计语言

Every screen must read as the same product if placed side by side.

## Design Read
像一台可靠的家用网络设备：主机与文件随手可达，网络策略清楚，数据紧凑而不拥挤。

## Identity and constraints
延续现有 tom-ps5-usbnet 青绿与等宽数据语言，用导航分组、扁平状态条和分隔列表体现设备控制台身份。不是营销页面。没有外部参考链接。
保留现有原生 HTML 按钮、表单、dialog 和表格组件；不引入 React、组件框架、外部字体或 CDN。此项是用户批准的现有栈整理方案，优先于另选设计系统的通用建议。中文使用本机 PingFang SC / Microsoft YaHei，拉丁与数据采用现有本机 UI/等宽回退，保证无网络和字体下载时可用。

## Locked colors

颜色以固定 hex 交付；保持现有蓝灰中性色倾向。状态使用文字和颜色双重编码。禁止紫蓝渐变、装饰光晕、玻璃面板、大面积渐变、嵌套阴影卡片、无意义数字与营销文案。

## Type and scales
- 页面标题 24px / 700，手机 20px；区块标题 15px / 650；正文 14px；辅助文字最小 12px；数据 12–13px 等宽。
- 间距仅用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px；主区桌面和平板外侧留白 16px，手机 12px，横屏安全区由同一个外层容器处理。标题栏与页面内容共享左右边界，内部常规面板留白 16px。
- 外层面板、标题栏与弹层统一 12px 圆角；按钮、输入框、搜索、菜单项等矩形控件统一 8px。紧凑细节可 4px，完整状态胶囊可 999px，指示灯保留正圆，分隔列表保持拼接直角；手机底部面板仅上角 12px。内层贴边背景的圆角减去外框 1px 边线。
- 默认无卡片投影；弹层可保留现有浮层阴影。
- 主内容随可用宽度铺开，取消独立的 1240px 居中上限，避免大屏重复留白；侧栏 224px；平板保留现有图标轨，手机阈值 767px。
- 主要操作每区一个，次要操作边框按钮，危险操作仅危险颜色；移动端触控目标至少 44px。
- 动效（2026-11-10 扩充）：按压反馈 160ms 微缩 0.97；入场 220ms / 退场 150ms，曲线 `--ease-out: cubic-bezier(.23,1,.32,1)`，抽屉类 `--ease-drawer: cubic-bezier(.32,.72,0,1)`。
  只在“路由切换、进入文件夹、弹层开合、新任务出现”时播放；轮询刷新不得重播（容器用一次性 `data-enter` 标记，传输卡片按 key 复用节点）。
  页面入场为淡入 + 6px 上移，子卡片 30ms 错落、最多 120ms；列表行 12ms 错落、最多 60ms。只动画 transform / opacity。
  键盘导航与筛选更新立即响应；`prefers-reduced-motion` 时只保留短淡入，去掉位移与呼吸动画。
- 小屏与触屏（2026-11-10）：手机不照搬桌面——弹出菜单与成排次要按钮改为底部操作面板，底部面板可下拉关闭，
  列表整行可点，路径条单行横滑并带返回键，工具栏次要操作为 44px 图标按钮；平板竖屏把放不下的表格改为分隔列表；
  任何触屏（`pointer: coarse`）触控目标 ≥44px、输入 16px；hover 效果只给精确指针。
- 传输进度使用全局浮动面板（右下角胶囊 + 展开列表，手机位于标签栏上方），不嵌入页面流；仅在有进行中或未查看的结果时出现。

## Signature
分为“工作台 / 网络管理 / 系统”的导航，以及一眼可见的主机、文件入口。状态条与真实设备数据形成连续的工具界面，不用海报式装饰。

## Voice
中文、简明、明确动词。统一“保存并应用”“回退上一版”“上传插件”“重新扫描”“清除筛选”。用户需要区分服务主机与 PS5 主机；任何 IP 都标注上下文。加载、未配置、无内容、无匹配、请求失败分别表达。
