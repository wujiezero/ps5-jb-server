          2. 
              
        2. 再在主机上停止并禁用服务：
          systemctl disable --now ps5-jb-host ps5-jb-server ps5-jb-repo
          3.

                删除插件文件？
                
      
                将从仓库中永久删除 ，PS5 端将无法再下载。此操作不可撤销。
                
      
                
    
                
    
                
      
      
    
                
                  

  
    
                
    
                
      
                退出 Payload Manager？
                
      
                将让 — 上的 pldmgr 自行退出（主机本身不会关机）。退出后此页面无法再安装插件或调整自动加载，直到在主机上重新运行 pldmgr.elf。
                
      
                
    
                
    
                
      
      
    
                
                  

  
    
                
    
                
      
                让 PS5 进入待机？
                
      
                主机 — 将进入待机（休息模式）。已运行的插件通常会留在内存中，唤醒后可继续使用；正在进行的 FTP / NAS 传输会中断。
                
      
                
    
                
    
                
      
      
    
                
                  

  
    
                
    
                
      
                
        
                配对遥控游玩
                
        
                配对后才能从待机唤醒并自动登录用户。只需配对一次；主机重置、删除或新建用户、IP 变化后需要重新配对。配对密钥由电源控制引擎加密保存，不会传到页面。

                更新主机上的插件？
                
      
                把主机 — 上的旧版本替换为插件仓库里的版本。正在运行的插件会先停止旧进程再启动新版本；未运行的只替换文件，下次加载时生效。
                
      
                  
      
                  「可能有更新」表示文件名不同但读不出版本号，请确认后再更新。文件服务类插件（ftpsrv、zftpd 等）在传输中被停止会中断传输。
