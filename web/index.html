    停用与回滚

    1. 先把 PS5 的默认网关改回家庭路由器，DNS 改为常用解析器。
    2. 再在主机上停止并禁用服务：
      systemctl disable --now ps5-host ps5-manager ps5-repo

    停止服务会关闭此容器的 IPv4 转发；原规则保留默认拒绝，避免意外漏放。若需要不可绕过的设备隔离，应由家庭路由器 / VLAN 实施。

    关于

    分类规则集
    v2fly/domain-list-community（MIT）编译的后缀规则

    限制
    共享 CDN 的同一 IP 可能承载多个域名；PS5 改换网关或直连同网段设备时不经过本机策略

    PS5 的漏洞链执行与 Payload Manager 启动仍需在真机上确认；网络测试中的互联网或 PSN 检查可能失败，因为初始白名单为空。
