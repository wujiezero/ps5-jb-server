## v1.9.1：网关网卡自动探测，DNS 不再排队

从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。**建议尽快升级到这一版**：之后前端会拆成多个文件，
只有 v1.9.1 及以后的升级器才能直接网页升级过去。

### 修复

- **网卡不叫 `eth0` 时网关完全不通。** 服务启动时把防火墙规则写死在 `eth0` 上，覆盖了安装器探测到的网卡。
  现在自动使用持有本机地址的网卡（再退到默认路由的出口网卡），也可以在 `config.toml` 的 `[network]` 里写
  `interface = "ens18"` 指定。当前使用的网卡显示在「设置 → 服务信息」。仍然只支持单网卡（PS5 的流量从同一块网卡进出）。
- **一个慢的上游 DNS 会拖慢所有查询。** 以前每条查询都要排队等前一条问完上游；现在内置域名、已缓存的域名和被拒绝的域名
  立即应答，同一个域名同时被多次查询时只问一次上游。查询期间修改了白名单，会按新白名单重新判断。
- **每解析一个新域名都整表重建防火墙。** 现在只把新地址追加进去，`nft` 调用减少到原来的三分之一，概览页的规则计数器
  不会再被频繁清零（保存策略时仍会清零）。

### 升级

- 不需要新的系统软件包，网页一键升级即可；配置、白名单、插件仓库与数据保持不变。
- 不需要修改 `config.toml`。只有自动探测选错网卡时才需要手动加 `interface`。
