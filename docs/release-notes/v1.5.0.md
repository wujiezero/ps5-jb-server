## v1.5.0：PS5 管家、插件上游更新与历史版本

服务改名为「PS5 管家」，插件仓库可以直接跟上游更新并随时回退，一键安装脚本会自己装好依赖。
从 v1.4.0 可以在「设置 → 服务更新」里一键升级到本版本，无需 SSH。

### 插件仓库

- 「检查更新」：对照 Payload Manager 官方源（itsPLK/ps5-payloads-mirror）查找新版本，列表里标出「可更新 → 新版本」。
  本地版本比上游新的插件不会提示。
- 单个「更新」或「全部更新」：下载后按上游 SHA-256 校验才写入仓库，名称、分类、描述等本地信息保持不变。
- 历史版本：更新或「替换」前的文件自动保留（每个插件最近 3 个，只存在本机、不提供给 PS5），可一键回退、再切回来，或删除。
  回退只改变仓库提供的文件；PS5 上已装的插件要在「PS5 主机」里重新安装才会换版本。
- 上传新插件时自动从文件名识别名称和版本（如 `zftpd-ps5-v1.7.0.elf`）。

### 安装与升级

- `bootstrap.sh` / `install.sh` 自动安装缺少的依赖：`git`、`python3`、CA 证书、`openssl`、`python3-dnspython`、
  `python3-cryptography`、`nftables`、`conntrack`、`procps`（sysctl）、`iproute2`，以及可选的 `python3-smbc`。以 apt 为主，dnf/yum/apk/pacman/zypper 尽力而为；
  加 `--no-deps` 只报告不安装。
- 重新运行安装脚本不再重置插件仓库：管理页上传的插件、编辑过的信息、更新或回退后的版本都会保留。
- 网页一键升级不会安装系统软件包。网络活动页需要 `conntrack`，如果之前没装，升级后在服务器上执行一次：
  `apt-get install -y conntrack`。

### 界面

- 新名字「PS5 管家」与新 logo，浏览器标签图标同步更换。

### 修复

- 网络活动：本机缺少 `conntrack` 时整页无数据并一直报「规则分类更新失败」。现在 DNS 查询照常显示，提示改为说明缺什么、怎么装，
  装好后提示自动消失。
- 在 PS5 上安装新版插件：先查询 pldmgr 的槽位，已有槽位用替换模式上传，修复 `zftpd.elf` 升级到 `zftpd-ps5-v1.7.0.elf`
  这类文件名变化时的 HTTP 500；上传后按槽位核实新文件，不会误运行同名旧副本，失败时不再悄悄改走 elfldr。
