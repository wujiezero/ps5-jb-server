## v1.9.0：插件分类下拉框，上游更新识别重复条目

从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 插件分类下拉框

- 「上传插件」和「编辑插件信息」里的「分类」可以直接下拉选择：仓库里已经用过的分类排在前面，其后是常用分类
  （Loader、Kernel、System、Networking、Files、Diagnostics）。
- 也可以直接输入：列表会按输入内容筛选；没有同名分类时，末尾出现「新建分类「…」」，选中即可新建。
  大小写不同的已有分类会自动统一，不会出现 `files` 和 `Files` 两个分类。
- 支持方向键选择、回车确认、Esc 收起列表。留空时仍按 `Uncategorized` 保存。

### 修复

- 仓库里同一个插件有两个条目时（例如手动上传的 `ps5upload-12.4.2.elf` 和安装器带的 `ps5upload_v12.4.2.elf`），
  其中一个从上游更新到 `ps5upload_v12.4.7.elf` 之后，另一个仍显示「可更新」，点「更新」只会失败并提示
  「仓库中另一个插件已使用文件名 ps5upload_v12.4.7.elf」。
- 现在这类条目在版本列标为「重复 · 最新版在「…」」，不计入可更新数量、也不显示「更新」按钮。确认无用后删除这一条即可，
  PS5 从另一个条目获取最新版。

### 升级

- 不需要新的系统软件包，网页一键升级即可；配置、白名单、插件仓库与数据保持不变。
