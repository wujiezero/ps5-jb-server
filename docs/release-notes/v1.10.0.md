## v1.10.0：NAS 传输自动重试与断点续传，任务重启不丢

从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 新功能

- **网络一抖传输就失败的问题少了。** NAS 传到 PS5 的过程中，单个文件遇到连接被重置、超时这类错误，会等几秒自动重试，
  默认最多 3 次；任务卡片会显示「自动重试 N 次」。PS5 用 FTP（如 zftpd）收文件时，会尽量从已传的位置接着传，
  不用把几十 GB 的文件从头再来（「续传 N 次」）。续传完会核对大小，不对就整文件重传。
- **服务重启后任务还在。** 传输和解压任务列表会保存下来，重启时没跑完的任务显示「已中断」，NAS 传输可以一键「重试」，
  已经在 PS5 上的文件自动跳过。
- **主机页记得上次发现的 PS5。** 启动后先探测上次见过的主机，扫描结束前显示「上次发现于 …」。

### 修复

- 解压任务完成后一直显示「进行中」，导致网页升级提示有任务在运行。

### 改进

- 管理页改用长连接并缓存静态文件，翻页和轮询更快、更省流量。

### 升级

- 不需要新的系统软件包，网页一键升级即可；配置、白名单、插件仓库与数据保持不变。
- 不需要修改 `config.toml`。想关闭或调整自动重试，在 `[limits]` 里加 `transfer_retries = 0`（或 1–10）。
- 断点续传依据 zftpd 源码实现，尚未在真机上验证；即使 PS5 端不按偏移写入，大小核对也会让它退回整文件重传。
