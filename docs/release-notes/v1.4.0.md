## v1.4.0：版本管理、GitHub 发版与网页更新

本版本加入统一版本号与网页服务升级机制，并包含 NAS 游戏解压归位、主屏幕注册适配和界面改进。

### 服务版本与更新

- 设置页和侧栏显示当前版本；可手动检查 GitHub 最新正式发布、查看发布说明和一键更新。
- 更新包经过长度及 SHA-256 校验，使用独立 systemd 执行器备份、替换、重启并验证服务。
- 保留配置、管理员密码、NAS 密钥、证书、白名单、插件仓库和用户数据。
- 升级失败尝试恢复旧程序；持久事务日志与恢复服务用于处理升级中断。回滚失败会报告单独错误。
- 传输、解压和仓库写入期间拒绝升级；升级期间拒绝新写入任务。
- 修复用户手册服务在管理服务重启后没有恢复的问题。

### 游戏与文件管理

- NAS 分卷 RAR 流式解压；libarchive 与独立 unrar 引擎按包类型选择，不在服务磁盘落地游戏内容。
- 按 eboot.bin 与 sce_sys/param.json 或 param.sfo 识别真实游戏根，去除多层外壳并按真实游戏编号归位。
- 解压完成后可通过本机 PS5Upload engine 注册主屏幕图标；需要运行对应引擎与 PS5 插件。
- 包内只有 PKG 不等于可运行 dump；金手指 ZIP 支持结构识别和导入规划，尚不代表任意 ZIP 都能全自动安装并刷新 etaHEN 缓存。

### 旧版本首次升级

旧版本没有网页更新执行器，需要通过 SSH 手动升级一次。从本版本开始，后续正式版本才可以使用网页更新。

```sh
git clone --branch v1.4.0 --depth 1 https://github.com/wujiezero/ps5-jb-server.git ps5-jb-server-upgrade
cd ps5-jb-server-upgrade
```

先备份原程序、配置、NAS key、证书和数据，等所有传输任务完成。标准安装布局再执行：

```sh
sudo systemctl stop ps5-jb-server.service ps5-jb-host.service ps5-jb-repo.service
sudo ./install.sh upgrade --no-payloads --no-manuals-host --no-firewall
sudo systemctl restart ps5-jb-server.service ps5-jb-host.service ps5-jb-repo.service
```

旧的 `/opt/ps5-manager` 手工部署不要直接套用标准路径，应按 [首次升级说明](https://github.com/wujiezero/ps5-jb-server/blob/v1.4.0/docs/releases.md#没有更新入口的旧版本首次升级) 部署文件并登记原服务。升级命令失败时，先处理或恢复备份，再启动服务。

### 验证范围

本地 Python 测试共 361 项，342 项通过、19 项因原生解压依赖缺失而跳过；前端测试 21 项通过。另已在 Debian 12 LXC 验证旧布局首次升级、服务依赖恢复及更新检查。网页跨版本升级的校验、失败和恢复流程经过隔离测试；本次没有在生产主机上执行跨版本更新演练。
