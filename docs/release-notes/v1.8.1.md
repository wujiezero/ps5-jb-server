## v1.8.1：插件更新与仓库历史的修复

复查 v1.5.0–v1.8.0 后的修复版本，不加新功能。从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### PS5 插件更新

- 版本比对把 `1.7` 和 `1.7.0` 当成不同版本：仓库写 `v1.7.0`、主机上是 `zftpd-ps5-v1.7.elf` 时会误报「可更新」，
  反过来会误报「主机版本较新」。现在比较前会去掉末尾的 `.0`。
- 「更新并应用」在 pldmgr 上传连接失败时，曾退回 elfldr 直接运行新版本并显示「已更新」，但主机上保存的仍是旧文件，
  下次自动加载又会回到旧版本。更新现在只通过 pldmgr 完成，失败会如实报错；旧进程已经停止时会提示到「运行中」确认后手动重新运行。

### 插件仓库

- 某个插件经上游更新改了文件名后（例如 `zftpd.elf` → `zftpd_1.7.0.elf`），再上传原来的文件名会和它共用同一个 `id`，
  两者共享「历史」，删除其中一个会连带删掉另一个的历史版本。新上传的插件现在总会拿到未被占用的 `id`。
- 上游更新或回退时，如果目标文件名已被另一个插件使用，会直接提示原因，不再显示成「应用失败…已尝试恢复上一份策略」。

### 界面

- 「访问策略」里的内置域名说明不再写死「3 个」，与服务端下发的列表一致。

### 升级

- 不需要新的系统软件包，网页一键升级即可；配置、白名单、插件仓库与数据保持不变。
