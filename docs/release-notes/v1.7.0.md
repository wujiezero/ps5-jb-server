## v1.7.0：主机插件一键更新、进度展示、功能说明与运行日志

一轮页面打磨：插件仓库更新后，PS5 上的旧版本会被提示出来并能一键更新；各类更新都能看到进度；每个功能旁边都有说明；
设置页可以查看和导出日志，方便反馈问题。从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### PS5 插件：与仓库版本比对、一键更新并应用

- 「PS5 主机 → 插件库」会把仓库插件和主机上的文件对上（按 pldmgr 的本地槽位），比较文件名里的版本号。
  主机比仓库旧时显示「可更新」，例如「主机 1.6.0 → 仓库 v1.7.0」；文件名读不出版本号时显示「可能有更新」。
- 「更新并应用」：旧版本正在运行就先停止旧进程，替换后启动新版本；没有运行则只替换文件，下次加载时生效。
  多个插件可以「全部更新并应用」，操作前会列出每个插件的处理方式供确认。
- 通过本服务安装的插件会记住安装时的文件，之后的比对更准确。
- 主机卡片、概览快捷入口，以及插件仓库页（上游更新之后）都会提示可更新的插件数量，并能直接跳到主机页更新。
- 修复：主机上文件名带版本号的插件（如 `zftpd-ps5-v1.6.0.elf`）以前会被误显示为「未安装」。

### 进度展示

- 服务更新：「下载 → 校验 → 备份 → 安装 → 重启 → 确认」步骤条，下载阶段显示已下载字节数。
- 插件上游更新：当前第几个、下载字节数与百分比。
- 主机安装 / 更新：「读取 → 上传 → 确认 → 启动」阶段与上传百分比，同时显示在对应的插件行里。

### 功能说明

- 各卡片标题和关键按钮旁新增「?」图标，鼠标悬停、键盘聚焦或触屏点按即可看到用途和用法，
  例如 NAS 的「流式解压安装」支持哪些压缩包、「安装」和「合并」的区别。

### 运行日志

- 「设置 → 运行日志」：按级别、关键字筛选，可自动刷新。
- 「导出日志」下载一个文本文件：诊断摘要、服务日志和本浏览器最近的错误提示，不含密码和会话信息，反馈问题时附上即可。
- 服务日志同时保存在数据目录的 `logs/service.log`（1 MB × 4 份轮转），服务重启后仍可导出。
- 页面定时刷新产生的成功读取请求不再写入 journal 和日志文件。

### 界面

- 内容超高的组件改为在组件内部滚动，不再把整页撑高：网关计数器、PS5 网络设置、自动加载列表、白名单输入框，
  以及桌面端的网络活动、插件仓库、主机插件库、文件列表（表头固定）。滚到底后滚轮继续带动页面。

### 升级提示

- 本版本不需要新的系统软件包，网页一键升级即可。
- 新增服务端模块 `server/logbook.py`。网页升级和安装器会自动带上；手工拷贝部署（例如旧的 `/opt/ps5-manager`
  平铺布局）时请一并复制。
