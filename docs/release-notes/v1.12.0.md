## v1.12.0：PKG 安装、金手指导入和游戏库

从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 新功能

- **从 NAS 直接装 PKG。** NAS 列表里的 `.pkg` 文件多了「安装 PKG」：PS5 直接从本服务读取 NAS 上的 PKG，
  不需要先拷到电脑或 PS5 上。需要本机装有 PS5Upload 引擎、PS5 上运行 ps5upload 插件。安装进度显示在传输任务里，
  可以取消；引擎正在忙另一个安装时，等它结束后点「重试」即可。
- **导入金手指。** 名字带「金手指」「cheat」「trainer」的 ZIP 可以一键写入 etaHEN 的金手指目录；解压安装游戏时，
  压缩包旁边的金手指 ZIP 也能顺带导入。导入后需要在 etaHEN 里重新加载金手指才会生效。
- **游戏库。** 新增「游戏库」页面，集中查看各个存储上的游戏：封面、名称、所在位置，按需计算大小，
  可以移动到其它存储、重新注册主屏幕图标或删除。通过 PKG 装到系统分区的游戏不在这里显示。

### 升级

- 不需要新的系统软件包，网页一键升级即可；配置、白名单、插件仓库与数据保持不变。
- 不需要修改 `config.toml`。PKG 安装默认使用 8090 端口（只在安装期间对目标 PS5 开放），
  端口被占用时在 `[ps5]` 段改 `pkg_port`，设为 0 关闭 PKG 安装；游戏库扫描的文件夹可用 `game_dirs` 调整。
- PKG 安装和金手指导入尚未在真机上验证，第一次使用时请留意结果。
