## v1.6.0：服务更新支持 HTTP 代理

GitHub 时通时不通的网络（国内常见 `The read operation timed out`）现在可以给服务配一个代理：服务更新和插件上游
都走它，PS5 与 NAS 仍然直连。从 v1.4.0 / v1.5.0 都可以在「设置 → 服务更新」一键升级，不需要 SSH。

### 代理

- 只从环境变量读取，代码里不含任何地址，一个都不设就是直连（行为与之前一致）：
  `PS5JB_PROXY`、`HTTPS_PROXY`/`https_proxy`、`HTTP_PROXY`/`http_proxy`、`ALL_PROXY`/`all_proxy`，
  按顺序取第一个非空值。
- 只接受 `http://` 或 `https://` 的 HTTP 代理（`urllib` 不支持 SOCKS）；只写 `192.168.1.2:6152`
  会自动补成 `http://`。
- 配置方式二选一：`sudo ./install.sh --proxy http://192.168.1.2:6152`，或写 drop-in
  `/etc/systemd/system/ps5-jb-server.service.d/proxy.conf`（旧 `/opt/ps5-manager` 布局为同名
  `ps5-manager.service.d/proxy.conf`）。详见安装文档的「代理」一节。
- 代理只作用于外网下载：PS5 控制与文件、NAS（WebDAV/SMB）、本机插件仓库和健康检查始终直连，
  所以不需要维护 `NO_PROXY`。
- 「设置 → 服务更新」新增「网络代理」一行：显示生效地址与来源变量、直连状态，或配置错误的原因
  （例如填了 SOCKS）。
- 网络类失败的错误提示会附带配置建议，不用去翻日志。

### 修复

- 「设置 → 服务更新」的「上次检查」把秒级时间戳当成毫秒，显示成 1970 年（例如 `01/22 01:56:09`）。

### 升级提示

- 本版本不需要新的系统软件包，网页一键升级即可。
