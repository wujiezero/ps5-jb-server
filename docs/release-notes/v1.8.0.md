## v1.8.0：内置域名说明

修一个会误导人的显示问题：`manuals.playstation.net`、`ena.net.playstation.net`、`www.msftconnecttest.com`
这三个「用户手册入口」域名由本机 DNS 固定应答，与白名单无关，但「网络活动」里一直显示为「允许」，
看上去像是白名单里多出了没配过的域名——其实它们从来不出局域网。

### 访问策略：白名单里的内置域名说明

- 「访问策略 → 访问白名单」在「允许的域名」下方新增说明块，列出这三个内置域名和当前主机 IP，
  说明它们固定解析到本机、不查询上游 DNS、不产生出网流量。
- 它们不在白名单里也始终生效：**加进白名单也不会改变任何行为**，所以不用填。说明块里的域名由接口下发，
  以后内置域名有变化，页面自动跟着变。
- 域名解析与网关策略本身没有任何改动。

### 网络活动：区分「本机劫持」和白名单放行

- 来自内置域名的 DNS 查询，在域名后面标注「本机劫持」，一眼就能看出它是本机直接应答的，
  不是白名单放行；结果列仍然只显示「允许 / 未放行」，不影响筛选、勾选和批量放行。

### 功能说明文案修正

- 「DNS 服务」「用户手册入口」「访问白名单」「网络活动」四处说明不再写「只解析白名单里的域名」这类
  与实际不符的说法，改为说明内置域名始终由本机应答。

### 升级

- 从 v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级；配置、白名单、插件仓库与数据保持不变。
- `GET /api/state` 新增 `local_domains`，`GET /api/activity` 的 DNS 事件新增 `local`；旧前端忽略即可，
  新前端拿不到这两个字段时自动隐藏说明块、不加标注。
