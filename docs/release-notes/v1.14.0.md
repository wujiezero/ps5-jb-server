## v1.14.0：游戏迁移与卸载

v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 新功能

- **游戏迁移。** 在内置存储和 M.2 / USB 硬盘之间搬游戏，内迁外、外迁内都可以，一次可选多个。
  复制完确认无误才删除原来的游戏，并自动在新位置重新注册主屏幕图标；中途失败原游戏不受影响，可以重试。
  入口在「游戏库」和「PS5 文件」页的「迁移游戏」。
- **游戏卸载。** 选中游戏一键卸载：删除游戏文件、移除主屏幕图标、清理它的金手指文件。
  内置、M.2、USB 硬盘上的游戏都支持，PKG 安装的游戏也会出现在游戏库里并可以卸载。
  存档默认保留，需要时可勾选一并删除。
- 迁移和卸载都在「传输任务」里显示进度，也可以设置完成通知。

### 升级

- 网页一键升级，不需要新的系统软件包，也不需要修改配置。
- 主屏幕图标、PKG 游戏和存档相关的操作需要 PS5Upload 引擎和 PS5 上的 ps5upload 插件。
- 这两个功能还没在真机上大量验证，第一次使用建议先拿一个小游戏试一下。
