# PS5 端设置与常见现象

## 一次设置

设置 → 网络 → 设定互联网连接 →（有线/无线）→ 高级设置：

| 项目 | 填什么 |
| --- | --- |
| IP 地址 | 自动获取（保持 PS5 自己的地址，**不要**填本机地址） |
| 子网掩码 | 自动 |
| 默认网关 | 本机地址（例如 `192.168.1.10`） |
| 主 DNS | 本机地址 |
| 次 DNS | 留空或同样填本机地址 |

只填 DNS 时：只有域名策略生效，管理页看不到连接记录。
同时填网关时：IPv4 流量经过本机，策略与“网络活动”才完整。

## 打开用户手册

设置 → 指南与提示 → 用户手册。正常情况下会命中本机的自签 HTTPS 站点（浏览器提示证书不受信任属正常）。

若仍是原来的页面：`dig @<本机> manuals.playstation.net` 应返回本机地址；否则检查 PS5 的 DNS 是否生效、
`ps5-jb-host` 是否在跑。

## 越狱之后

1. 在 PS5 上运行 `pldmgr.elf`（Payload Manager）或 `elfldr`。
2. 打开管理页 `#/ps5` → 重新扫描 → 看到主机后点「接入本服务仓库」。
3. 之后即可「安装并运行」本机仓库里的插件；「自动加载」控制开机自动运行的列表；
   「运行中」可停止进程；「关机」会关闭 pldmgr（主机重启后需重新越狱）。

## 文件管理

需要 PS5 上运行提供 `/fs/*` 接口的服务（例如 `tom-ps5-usbnet.elf`）。它会在 PS5 上暴露一个 HTTP 文件服务，
管理页 `#/files` 选择该主机后即可浏览 `/data`、`/mnt/ext*`、`/mnt/usb*`。

- 上传/下载都经本机代理，不经过互联网；
- 路径白名单只允许上述三个位置；
- 覆盖、删除、复制/移动都会二次确认。

## 停用与回滚

先把 PS5 的默认网关改回路由器，再：

```sh
sudo ./install.sh uninstall          # 保留数据
sudo ./install.sh uninstall --purge  # 删除数据
```

不要手工 `nft flush ruleset`：本服务的表是 `inet ps5guard`，停服务时由 unit 负责关闭转发。
