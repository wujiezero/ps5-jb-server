# 管理控制台布局统一验证

日期：2026-11-10。代码基线：`5f542cf`，本次运行时代码仅修改 `web/style.css`；测试、设计约定及本文档同时更新。

## 修改内容

- 七个路由统一使用父容器提供的外侧留白：桌面/平板 16px、手机 12px；标题栏与正文区块外边缘对齐。
- 移除标题栏和正文各自的 1240px 上限，大屏按剩余空间铺开；保留独立登录页的布局，应用主区域选择器限定为 `#main`。
- 标题栏、卡片、弹层使用 12px 圆角；矩形控件使用 8px；状态胶囊、圆形灯号、进度条及拼接列表保留各自语义。文件栏贴边背景采用扣除 1px 边框的内圆角。
- 修复手机概览折叠面板重复内边距，并使用内侧焦点轮廓防止键盘焦点被裁掉；主机详情滚动定位给固定标题栏和安全区保留空间。
- 修复未配置 NAS 时提示在小屏横向存储栏中被挤成竖列；统一常规面板内边距、设置提示及表单操作间距。


8 项 Node 前端交互测试通过。浏览器场景由 `tests/browser/console-smoke.js` 导出，Playwright 调用现有 Page 执行；测试静态资源通过受控的 loopback HTTP 服务提供。

- 浏览器场景 15 项全部通过，无 JavaScript 异常、无写请求。
- 7 个路由 × 9 个宽度（320、390、767、768、1023、1024、1440、1920、2560px）× 明暗 2 主题，共 126 组布局检查通过。
- 检查的是 `.app-bar` 与可见 `.view` 的实际边缘，包含侧栏边界、浏览器稳定滚动条占位、公共面板/控件圆角与页面横向溢出，容许 1px 舍入误差。
- 额外检查概览折叠框内边距、文件栏角落、空 NAS 提示、键盘焦点轮廓、主机详情与固定标题栏间距、登录页 4 种宽度、更多菜单关闭与焦点恢复、筛选/搜索、加载失败恢复及会话过期。
- 原浏览器脚本对原生 dialog 异步 close 事件及新退出动画使用了立即判断，现改为等待实际隐藏、焦点与 ARIA 状态；空仓库等待条件改为精确的零数量前缀，避免误匹配总字节里的数字 0。补齐当前前端读取的 NAS、统一传输和标题 API 测试响应。

修复前浏览器复现：84 组检查记录 252 个对齐/留白/圆角违规。1440px 文件页中，标题左边界为 224px、正文 248px；修复后两者均为 240px。1920px 文件页可用正文宽度从 1192px 增至 1649px，两侧保持统一 16px 外留白。

独立静态审查发现的折叠框焦点裁切和主机详情滚动偏移均已修复，并新增浏览器验证。
